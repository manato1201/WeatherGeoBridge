# 用語集

| 用語 | 意味 |
|---|---|
| **Worker** | Cloudflare Workers 上で動く、この API(`worker/`)。Hono で書いてある |
| **Hono** | Worker 向けの軽い Web フレームワーク。ルートとミドルウェアを書く |
| **KV** | Cloudflare の key-value ストア。このツールでは `WEATHER_CACHE`(天気)と `PUSH_SUBSCRIPTIONS`(購読) |
| **Open-Meteo** | 天気・大気質を返す無料の外部 API。このツールのデータの出どころ |
| **観測(observation)** | いまの天気(気温・湿度・降水量・風など)。`WeatherObservation` |
| **予報(forecast)** | 日ごと・時間ごとの先の天気。`Forecast` |
| **系列(series)** | 複数地点の +72 時間・3 時間刻み(25 点)の予報。アトラスの時間スライダー用 |
| **メッシュ(grid)** | 中心と範囲から作る n×n の格子点の系列。地図の色塗り用 |
| **丸めキー(`roundKey`)** | 緯度経度を小数 2 桁にしたキャッシュのキー。約 1 km の格子 |
| **使える期限(`TTL_SECONDS`)** | キャッシュを使い回してよい時間(600 秒)。`fetchedAt` を見て自分で判定する |
| **捨てる期限(`KV_ENTRY_EXPIRATION_SECONDS`)** | KV が値を消す時間(7 日)。使える期限より必ず長くする |
| **差分(`WeatherDiff`)** | 前回と今回の観測の違い(降り始めたか・気温の差)。通知の「事実」 |
| **通知の条件(`NotificationPreferences`)** | 購読者ごとの、降水通知の有無・気温急変の閾値(既定 5.0℃) |
| **購読(subscription)** | ブラウザの Web Push の登録。endpoint・鍵・条件・**地点**を持つ |
| **Web Push** | ブラウザへ、サーバーから通知を送る仕組み。送り先はブラウザごとのプッシュサービス |
| **VAPID** | Web Push の送り手を証明する鍵の仕組み。公開鍵と秘密鍵がある |
| **Cron トリガー** | 決まった間隔で Worker の `scheduled` を呼ぶ仕組み(15 分ごと) |
| **`X-API-Key`** | 呼び出し元を確かめるヘッダー。鍵はサーバー側だけが持つ |
| **`X-Client-IP`** | Next.js が転送する利用者の IP。レート制限の数え方に使う |
| **fail-closed** | 設定が足りないとき、通さずに閉じる設計(鍵が未設定なら 503) |
| **CORS** | ブラウザが、別のオリジンの API を呼べるかの取り決め。許可リスト方式にしてある |
| **MCP** | AI から道具を呼ぶための取り決め。`mcp_server/` が、天気と判断のツールを出す |
| **`DECIDERS`** | 判断(傘・洗濯)の関数を登録する辞書。同じ入出力の関数に差し替えられる |
| **`evidence`** | 判断の根拠(しきい値・ピーク時刻・現在の降水量など)。答えと一緒に返す |
| **`basis`** | 「確率は Open-Meteo の予報で、保証ではない」と断る一文 |
| **`unknown`** | 判断に要るデータが無いときの答え(`yes`・`no` と並ぶ 3 つ目) |
