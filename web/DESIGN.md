# DESIGN.md — WeatherGeoBridge の見た目の決めごと

新しい画面や部品を足す(AI に頼む場合も)ときは、この文書を渡す。値の出どころは `app/globals.css`(トークン)と `lib/mark.tsx`(マーク)。食い違ったらコードを正とし、この文書を直す。

背景: [QUALITY_UPLIFT_2026-11-09.md](../../QUALITY_UPLIFT_2026-11-09.md)(QL1〜QL4)。手本は [Portfolio/DESIGN.md](../../Web/Portfolio/DESIGN.md)。**図鑑・運用ツールの中でも、このサイトは「核が表現」(層 G2)**。天気の動き・電光掲示・3D の要素は製品の中心なので、Portfolio より動きが多い。

## 1. 方針

- **計器のように読める**。暗い地・細い罫線(1px)・影なし。奥行きは 3D のテレメトリー要素だけが担う(`--shadow-card: none`)。
- 赤(`--color-ember`)は**図形・縁光とエラー専用**。UI のクロム(ボタン・入力)には使わない。文字の赤は `--color-danger-text`。
- 差し色 `--color-accent` は、トップの見出しの 1 語だけ。

## 2. 色(2 テーマ)

既定はダーク(`:root`)。ライトは `:root[data-theme="light"]` と、システムがライトのときの `@media (prefers-color-scheme: light)` の 2 か所で同じ値を定義している(**両方を直す**)。部品はトークンだけを使い、色を直書きしない。

| トークン              | ダーク    | ライト    | 用途                                     |
| --------------------- | --------- | --------- | ---------------------------------------- |
| `--color-canvas`      | `#12130f` | `#f5f5f5` | 地                                       |
| `--color-paper`       | `#1a1b16` | `#ffffff` | カード                                   |

### 2.1 コントラスト(2026-11-11 の実測)

基準: 通常の文字 4.5:1 以上、大きい文字 3:1 以上(WCAG 2.x AA)。`/`・`/dashboard`・`/atlas` の全テキスト(29 / 65 / 101 要素)の実際の色と背景を、**ライト・ダークの両方**で測った。**基準未満は 0 件**。最小は 4.67:1(ダーク。補助文字 `#8a8a82` を一段上の面 `#202119` に置いたとき)。

**測定で見つかり、直したもの**

| 問題                                 | 前                                           | 後                                                              |
| ------------------------------------ | -------------------------------------------- | --------------------------------------------------------------- |
| ライトの補助文字(`--color-mid-gray`) | `#737373` → 地 `#f5f5f5` で **4.35:1**       | `#6b6b6b` → 4.89:1                                              |
| エラー文字(`.text-destructive`)      | `#e7000b` → ライト 4.38:1・ダーク **3.91:1** | テーマ別の `--color-danger-text` → ライト 5.75:1・ダーク 6.11:1 |

**測るときの注意**: 色に `transition` があるので、**測定中は `transition` と `animation` を止める**(止めないと、切替直後の途中の色を読んで、合否を誤る。背景のタブでは遷移が進まず、1 回前のテーマの色を読んだ)。

## 3. 動き

### 3.1 トークン(いまある)

| トークン          | 値   | 使う場面                           |
| ----------------- | ---- | ---------------------------------- |
| `--motion-fast`   | 0.3s | テレメトリー要素のインラインの遷移 |
| `--motion-medium` | 0.6s | 同上(値の変化)                     |
| `--motion-slow`   | 0.8s | 同上(大きな値の変化)               |

`prefers-reduced-motion: reduce` では、3 つとも **0s**(インラインの遷移もまとめて即時になる)。ループする動きは、`@media (prefers-reduced-motion: no-preference)` の中だけに書く(reduce では動かない)。UI の押す・出現は、`.btn:active { transform: scale(0.96) }`・`fade-in-up`(0.5s)など。

### 3.2 規則(Portfolio と共通のもの)

1. 動かす性質は **`transform` と `opacity`** を基本にする。レイアウトを動かさない。
2. **新しい動きは、必ず `no-preference` の中に書く**。時間は `--motion-*` を使い、値を直書きしない。
3. 動きを足す前に、その画面の状態(通常 / ホバー / 押下 / 無効 / 読み込み中)を書く。
4. 見せ場は **1 画面に 1 つ**。管理・設定の画面に重い演出を置かない。

### 3.3 無限ループの一覧(2026-11-11 時点・全部 `no-preference` の中)

| 名前                        | 内容                           | 分類                                                                                                                             |
| --------------------------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `rain-fall` / `cloud-drift` | 天気のイラスト(雨・雲)         | **製品の核**(G2)。残す                                                                                                           |
| `cloud-boil`                | 雲の輪郭の揺らぎ(`steps`)      | 製品の核(G2)。残す                                                                                                               |
| `skeleton-shimmer`          | 読み込み中の表示               | 規則の例外(読み込み中)。残す                                                                                                     |
| `pulse-glow`・`blink`       | 「ライブ」の印の点滅(1.4s・2s) | 状態の表示。点滅は **3 回/秒未満**(いまは約 0.7・0.5 回/秒)                                                                      |
| `marquee-run` | 電光掲示の自動スクロール(38s) | 製品の核の一部として残す。**止められる**(止めるボタン・ホバー・フォーカスで一時停止)。reduce では流さず、折り返して静止表示 |

## 4. アイコン

- **マーク**: 暗い角丸の正方形(32 格子、`rx=7`)に、太さ 2.4 の「W」と、その上に ember の点(太陽 / 熾火)。**1 か所で定義**: `lib/mark.tsx`(`MarkSvg`)。`app/icon.svg` は同じ図形で、ブラウザが暗いときは明暗が反転する。
- **一式**(すべてこのマークから作る): `icon.svg`・`favicon.ico`(16 / 32 / 48px)・`apple-icon`(180px)・`icon-192` / `icon-512`(PWA)・`manifest.ts`・`opengraph-image`(英数字だけ。日本語フォントを同梱しないため)。
- **検査**: 16px で「W」と点が判別できること。対比: W/タイル 14.1:1、点/タイル 3.9:1(図形は 3:1 以上)。

## 5. 検査
